# Project status

## Included as code
- NestJS backend
- Prisma/PostgreSQL data model
- seed/demo data
- JWT authentication and roles
- student dashboard API
- lecturer dashboard API
- attendance credential + check-in
- absence processing
- materials upload
- OpenAI Smart Catch-up integration + offline fallback
- server-side quiz scoring
- badge rules and issuing
- Apple Wallet pass generator
- React student/lecturer/terminal web UI
- SwiftUI student app
- optional OpenCV terminal
- setup scripts and thesis diagrams/docs

## Requires your local/external configuration
- npm dependency installation
- Docker PostgreSQL runtime
- OpenAI API key for real AI output
- Apple Developer account + Pass Type certificate for real `.pkpass`
- Mac/Xcode for native iOS build
- production hosting/domain/HTTPS if you deploy outside localhost

## Deliberately not required for MVP
- Apple NFC entitlement
- university SSO
- production admin portal
- real grade/SIS integration
- App Store publication
